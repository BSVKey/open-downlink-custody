# Contributing

Requests, corrections and edits are welcome from everyone, and especially from the
Libre Space Foundation and SatNOGS station operators. If this tool reads the network in
a way you would like changed (request rate, caching, what is recorded, how SatNOGS is
credited or named), open an issue and we will adjust.

- **Issues:** bugs, feature requests, data or attribution concerns.
- **Pull requests:** keep changes small and include a test (`npm test`, offline, no
  network). Zero runtime dependencies is a project rule.
- **Privacy:** never add fields that record station coordinates, hostnames or other
  personal details of station operators.

By submitting a contribution you agree it is licensed under Apache-2.0, as described in
section 5 of the LICENSE.

Security issues: please report privately to embryospace@gmail.com rather than in a
public issue.
